# 幺筒麻将 · 75 秒入门规则片（v2）制作脚本

- 成片：`work/promo/yaotong-mahjong-rules-75s-9x16-v2.mp4`
- 规格：1080×1920 / 30 fps / 75.0 s / H.264 + AAC
- 依据：`docs/幺筒麻将规则-v1.0.md`（文件内 v1.7）
- 定位：**先让零基础观众知道“轮到我怎么做、什么时候能胡”，再谈牌型细节。**
  龙七对、地龙、特殊加分表、完整计分放到下一集。

## 1. 与 v1 的差异（按审片意见）

| 意见 | v2 处理 |
| --- | --- |
| 成牌不等于能接炮（最大缺口） | 新增 45–58 s 整段：自摸 ✓ / 接普通炮分条件（无杠鸡胡 ✗、有杠 ✓、大牌 ✓、报听原报 ✓），并用“硬胡＋10 ≠ 接炮资格”单独强调 |
| 最基本的一轮怎么打 | 新增 9–14 s：13 张手牌分两行，摸一张（金圈标记）→ 打一张（飞到牌河） |

| 幺筒如何代牌 | 26–30 s：二万、幺筒、四万留出缺口，幺筒滑入并标注“当三万”，括号写“顺子 234 万 · 幺筒代三万”；31–35 s 对照“碰三万 ✗ / 幺筒自己可以碰 ✓” |

| 报听有收益也有操作限制 | 66–70 s 卡片：报听＋20、原报＋40；“声明后不能改牌、不能碰杠；没胡就摸什么打什么”，并加一行“过胡、必须胡（杀报 / 手中有幺筒遇抢杠、热炮）另有约束” |

| “13 张手牌，摸到/胡到第 14 张成牌” | 标题下改为“**未开杠时 14 张；碰出、杠出的牌也算面子**”，成牌演示也以“4 组面子＋1 对将”呈现 |

## 4. 画面规则

- 教学段所有牌张按 1080 宽重新排布：结构页 8＋6 两行，手牌页 7＋6 两行，碰杠页单行放大（约 170 px/张），不再把 14 张压成一条细带。
- 分组用金色括号 ＋ 名称；错误示例用红括号、红叉；“正被解释的牌”只用金色高亮（金圈、金括号、金标签），不做无意义闪烁。
- 标题继续用衬线字；正文、括号、字幕用无衬线字，最小 26 px（1080 宽下约等于手机 13 px），不再依赖细小暗金字。
- 字幕固定在画面下部 1320–1420 区域，逐句出现，不提前泄露下一步；底部保留 7 段进度条。
- 色彩沿用 `#061a12 / #f6f0df / #d9b961`；开头立体幺筒沿用 v1 的模型与灯光。

## 5. 音频

## 6. 复现

```powershell
# 1) 预览服务（127.0.0.1:5174）
node node_modules/vite/bin/vite.js --config work/promo/vite.render.config.mjs

# 2) 渲染 2250 帧
node work/promo/render-rules75-v2.mjs

# 3) 音频
python work/promo/make_sfx75_v2.py
# 再执行 build-audio75-v2.ps1 中的 ffmpeg 命令（PowerShell 执行策略可能拦截 .ps1）

# 4) 编码
ffmpeg -framerate 30 -i D:/temp/yaotong-frames-rules75-v2/f%05d.jpg `
  -i work/promo/audio/mix-75-v2.m4a -c:v libx264 -preset slow -crf 18 `
  -pix_fmt yuv420p -profile:v high -level 4.1 -c:a aac -b:a 192k -shortest `
  -movflags +faststart work/promo/yaotong-mahjong-rules-75s-9x16-v2.mp4
```
