**版本：** v1.7

**适用范围：** 四人幺筒麻将，包含本项目线上对局与轮庄约定。

## 1. 基本配置与术语

### 1.1 牌具与基本操作

- 四人使用108张牌：万、筒、条各一至九，每种四张；无字牌、花牌。
- 可以碰、杠、胡，不吃牌。碰出的三张牌同向平放，不用横牌指向放碰者；来源记录仍用于责任计分。
- 四家起手各13张，庄家不跳牌，发牌完成后由庄家先摸本局第一张牌。
- 杠按一组面子计算；成功杠后从牌尾补一张，再按正常规则处理胡牌或出牌。
- 本局出现一般包牌、合法胡牌或流局时，进入对应终局结算。

### 1.2 术语

| 术语 | 含义 |
| --- | --- |
| 幺筒 | 一筒，可作本牌，也可作癞子；采用独立计分 |
| 幺鸡 | 一条 |
| 固定鸡 | 幺鸡、八筒、一万，亦称普通鸡 |
| 牌河 | 本人打出后仍留在本人面前、未被别人取走的牌 |
| 听牌 | 再来一张合适的牌即可形成合法胡牌的状态 |
| 报听、原报 | 在指定时点主动声明的状态，与普通听牌不同 |
| 自摸 | 自己摸到使自己成胡的牌 |
| 点炮胡 | 胡别人打出的牌，出牌者称放炮家 |
| 碰 | 用手中两张同牌，接别人打出的同牌，组成一副刻子 |
| 指示牌 | 结算时从剩余牌墙牌头翻出的一张牌 |
| 翻牌鸡 | 指示牌按同花色顺位加一所确定的牌种 |
| 责任家 | 幺筒碰、杠或点炮中承担专门责任款的一家 |

| 一巡 | 过手限制的计时单位，以本人下一次实际摸牌为解除时点 |
| 荒庄 | 牌墙耗尽，完成末张出牌响应后仍无人胡牌，按流局结算 |
| 小局 | 从重新准备牌墙、掷骰和发牌开始，到普通胡牌、一般包牌或流局结算结束的一局 |
| 庄次 | 同一位玩家连续坐庄的一段，可包含多个小局；连庄期间庄次编号不变 |
| 整场 | 开场选定的东风场、半庄场或全庄场，分别完成4、8或16个庄次后结束 |

本文件的“本局”指当前小局；“全局双倍”指该小局全部适用分数双倍。

听牌不等于已经报听，也不要求具备普通点炮胡资格。无杠鸡胡只要处于可自摸成胡的听牌状态，也属于听牌者。

### 1.3 分项记账

结算须区分：**胡牌分、鸡分、杠分、幺筒责任分、见面礼、杀报加分、一般包牌赔付、流局赔听款**。

普通胡牌的一份总分记为H，已含基础5分及成立的牌型加分。一般包牌和流局赔听使用自己的计价规则，不直接照搬H。

## 2. 定骰、抓牌与牌尾流程

### 2.1 定骰与起牌位置

每个小局开局均掷两枚骰子，连庄的小局也重新掷骰、抓牌。同一次掷骰结果用于确定取牌方、保留列数和该小局是否双倍。

以本次掷骰者的座位为“自己方”，先看**两枚骰子的点数之和**，确定从哪一方牌墙取牌：

| 两骰总点数 | 取牌方 |
| --- | --- |
| 5、9 | 自己方 |
| 2、6、10 | 下手方，即右手方 |
| 3、7、11 | 对方 |
| 4、8、12 | 上手方，即左手方 |

确定取牌方后，以**较小那枚骰子的点数**确定保留列数。小点数为n，就保留n列，从第n＋1列开始取牌；两骰同点时，按这个相同点数确定列数。

- 例：骰子为3和6，总点数9，从自己方牌墙取牌；小点数3，保留3列，从第4列开始取。
- 例：骰子为3和3，总点数6，从右手方牌墙取牌；保留3列，从第4列开始取，并触发本局同点双倍。

这里的保留列数用于确定开局取牌起点。留出的牌仍属于可用牌墙，后续按既定摸牌、补牌流程使用，牌尾仍一直摸到无牌。取牌方只决定牌墙起取位置，四家仍各取13张，庄家不跳牌，随后由庄家先摸第一张牌。

### 2.2 对局流程

1. 按第12.1节确定本小局庄家，准备牌墙并掷两枚骰子，按第2.1节确定取牌方和起取列，记录是否同点双倍，四家各取13张牌。
2. 在庄家第一次摸牌前，符合条件者可声明原报。
3. 庄家先摸牌，随后按行牌顺序进行摸牌、出牌及胡、碰、杠响应。
4. 满足报听时点与条件的玩家，可声明报听。
5. 同一张牌有多家合法胡牌响应时，允许同时胡牌；无人胡时再继续有效碰杠或后续行牌。
6. 触发一般包牌立即结束，执行一般包牌结算；否则有人合法胡牌时结束并结算全部合法赢家。
7. 无人胡且牌墙耗尽，按末张流程进入流局。

### 2.3 牌尾流程

**一直摸到牌尾，不提前留若干张停摸。** 杠后从牌尾补牌，没有可补牌时不再开杠。

最后一张仍可按正常资格自摸；未胡则出牌。最后打出的牌可以被胡、碰，不能杠。允许的碰牌须完成相应出牌与响应；最终无人胡且无牌可正常摸时流局。没有额外“海底捞月”加分。

**牌墙空了不翻鸡。** 不从手牌、牌河等处另取替代指示牌，不产生本局翻牌鸡，也不触发翻鸡三倍和因翻中该牌而增加的第五份奖励。其他分项按相应终局规则处理。

## 3. 癞子用法与胡牌资格

### 3.1 幺筒作本牌或癞子

幺筒作癞子组牌没有额外使用限制，可替代牌组成顺子、刻子、将、七对和龙头；同一组可以使用多张癞子，也可以用全癞子组成将或刻子。实际可用数量受四张幺筒的牌组上限限制。

- 清一色、金钩钓、龙头等按替代后的牌值和花色认定。
- 自摸或胡来的幺筒均可按合法拆解作本牌或癞子。
- 癞子不能替代其他牌进行碰、杠。例如“三万＋幺筒”不能碰三万。
- 幺筒按一筒本身组成碰、杠，可以正常进行。
- 幺筒可以打出；打出的仍是一筒，按幺筒冲分规则处理。

### 3.2 鸡胡与普通点炮胡

鸡胡是没有任何牌型加分的普通小胡，通常为四组顺子或刻子加一对将；有硬胡等加分时按实际项目显示。普通点炮资格仍依下表判断；与手中有无鸡、鸡分多少无关。

| 状态 | 自摸 | 普通点炮胡 | 抢杠、接热炮 |
| --- | --- | --- | --- |
| 鸡胡，无杠且无报听、原报等其他资格 | 可以 | 不可以 | 可以 |
| 鸡胡，自己已有明杠、暗杠或补杠 | 可以 | 可以 | 可以 |
| 碰碰胡、清一色、金钩钓、七对系列、地龙系列 | 可以 | 可以，无需自己有杠 | 可以 |
| 已声明报听或原报，且满足相应规则 | 可以 | 可以 | 可以 |

本玩法把具备点炮胡资格的牌统称“大牌”；称呼本身不额外加分。

**硬胡加10分不提供普通点炮胡资格。** 仅有硬胡加分的鸡胡，在无杠、无其他资格时仍不能接普通炮。各种胡牌均须满足成牌与场景条件；抢杠、热炮优先于过手限制。

### 3.3 抢杠、热炮与多家同时胡

- **抢杠：** 胡别人用于补杠的那一张牌。鸡胡也能抢杠，无需自己先有杠。
- **热炮／杠上炮：** 胡别人杠后补摸、紧接着打出的那张牌。鸡胡也能接热炮。
- **一炮多响：** 同一张牌允许所有合法声明者胡牌，最多三家。
- 各赢家分别按自己的牌型计算H，由放炮家分别支付；赢家之间不互付这些点炮胡牌款，鸡分仍按第6.2节逐家结算。
- 共同胡牌张分别给各赢家计鸡分。固定鸡按每位赢家各2分的原值计，再应用适用倍率。
- 共同胡牌张为幺筒时，放炮家分别向各赢家支付适用责任款；各赢家是否另有本牌10分、责任是否乘3，按各自合法拆解确定。

## 4. 牌型、加分与高点法

### 4.1 基础分与常规牌型

**普通胡牌基础分为5，另加成立且允许叠加的牌型分。**

| 牌型 | 牌型分 | 结构 |
| --- | ---: | --- |
| 碰碰胡 | 10 | 四组面子均为刻子或杠，另有一对将 |
| 清一色 | 20 | 胡牌用牌按实际采用的牌值均属同一花色 |
| 金钩钓 | 20 | 已碰、杠出四组面子，手中单张等待配将 |
| 七小对 | 20 | 七组对子 |
| 龙七对 | 40 | 七对中有一个四张同牌的龙头 |
| 双龙七 | 80 | 七对中有两个龙头 |
| 三龙七 | 120 | 七对中有三个龙头 |
| 地龙 | 40 | 已碰一副刻子，手中五对，胡入同种第四张；结构为4＋2＋2＋2＋2＋2 |
| 双地龙 | 80 | 按地龙方式胡牌，手中另有一个未开杠龙头及三对；结构为4＋4＋2＋2＋2 |
| 三地龙 | 120 | 按地龙方式胡牌，手中另有两个未开杠龙头及一对；结构为4＋4＋4＋2 |

地龙系列只碰出一副刻子，胡牌前手中为10张。胡牌张与已碰的三张组成地上的龙头；其他龙头保留在手中，不先开杠。幺筒可按癞子用法补成龙头。已经把该副牌开杠，再胡另一种牌，不算地龙。

例：已碰二筒，手中“三筒×4、二万×4、五条×2”，胡第四张二筒，构成三地龙。

### 4.2 特殊加分

| 项目 | 加分 | 条件 |
| --- | ---: | --- |
| 硬胡 | 10 | 整手所选胡牌拆解中没有使用癞子 |
| 报听 | 20 | 本人首次摸牌后，首次出牌进入听牌并主动声明，此前不能有碰、杠 |
| 抢杠 | 20 | 胡别人补杠的那张牌 |
| 热炮 | 20 | 胡别人杠后补摸紧接着打出的牌 |
| 素胡／不求人 | 20 | 门清、不求人自摸；胡牌用牌无固定鸡、幺筒、翻牌鸡；本人无碰、无杠，且非抢杠、热炮、杀报情形 |
| 原报 | 40 | 庄家首次摸牌前已听牌，并主动声明 |
| 天胡 | 40 | 庄家本局首次摸牌即自摸；本人此前没有碰、杠、出牌，且不是杠后补摸 |
| 地胡 | 40 | 闲家本局首次摸牌即自摸；本人此前没有碰、杠、出牌，且不是杠后补摸 |

素胡要求不求人自摸，无碰杠；检查手牌及胡牌张，不检查牌河，不与硬胡等任何其他项目叠加。存在翻牌鸡时，翻鸡后再复核素胡条件。天胡、地胡与报听共用本人首次摸牌资格：本人此前不能有碰、杠和出牌；首次实际摸牌若为杠后补摸，也不成立。仅检查本人的动作，其他玩家此前碰杠不取消本人资格。庄家显示天胡、闲家显示地胡，两者牌型分均为40。

### 4.3 叠加与择高

1. H＝基础5＋同一合法拆解中成立且允许叠加的牌型分。
2. 硬胡可以与其他成立项目叠加。
3. **素胡不与其他牌型叠加**，但仍有基础5，因此素胡计25。
4. 七对系列只取最高档；地龙系列也只取最高档，不累计同系列低档。
5. 胡牌牌型及幺筒本牌／赖子用法须在翻鸡前确认，玩家此时不知道指示牌。普通胡牌直接确认；只有赖子大牌的几种合法胡法在不同翻鸡结果下确实存在收益取舍时，才并列显示相应胡牌按钮。确认后翻鸡，只在已确认的牌型和本牌／赖子张数内择高，不得事后改成另一种胡法。未手选的普通指令及机器人按翻鸡前已知得分确认，不能读取实际指示牌。赖子的具体替代牌值可在已确认方案内按实际翻鸡择高；结算展示最终采用的牌型和用法。
6. 不同方案不能拼接。例如用癞子才成立的清一色，不能再借另一种无癞子拆法的硬胡10分。
7. 已碰、杠的组合不重新拆开；不能在当前场景合法胡牌的方案不参加择高。

| 成立项目 | H |
| --- | ---: |
| 无其他加分的鸡胡 | 5 |
| 碰碰胡 | 5＋10＝15 |
| 清一色 | 5＋20＝25 |
| 龙七对或地龙 | 5＋40＝45 |
| 双龙七或双地龙 | 5＋80＝85 |
| 三龙七或三地龙 | 5＋120＝125 |
| 碰碰胡＋清一色＋硬胡 | 5＋10＋20＋10＝45 |
| 素胡 | 5＋20＝25 |

**本牌幺筒10分与硬胡10分是两个项目。** 前者是每张幺筒作本牌时的鸡分，后者是整手无癞子的牌型分，只计一次。两张幺筒都作本牌可计20鸡分，整手无癞子时还可有硬胡10；一张作癞子、一张作本牌，则本牌那张仍有10鸡分，但整手不计硬胡。

### 4.4 胡牌款付款人

| 胡牌方式 | 谁付一份H | 赢家收到的胡牌款 |
| --- | --- | ---: |
| 自摸 | 另外三家各付H | 3H |
| 普通点炮 | 放炮家付H | H |
| 抢杠 | 被抢杠的补杠者付H | H |
| 热炮 | 杠后放炮者付H | H |

抢杠、热炮的20加分先计入H，不再在H之外重复加。杀报、鸡分、杠分、责任款和见面礼按各自规则另结。

## 5. 报听、原报与杀报

### 5.1 声明及操作限制

- **报听：** 本人此前没有碰、杠和出牌，摸到本局第一张牌后首次打出一张进入听牌，可声明报听。
- **原报：** 庄家首次摸牌之前已经听牌，可声明原报；四家均可满足该条件，不限庄闲。
- 声明后不可改牌，未胡时摸切，不通过碰牌或替换手牌改变原听口。
- **报听、原报后都不允许再杠，听口不变也不能杠。**
- 声明者可以胡别人打出的牌，也可能被别人胡其出牌；被杀报另按下款处理。

### 5.2 被杀报的付款

声明者自己点炮给别人，或别人自摸时，该声明者被杀报：

- 报听者向赢家付H＋20。
- 原报者向赢家付H＋40。
- H只含赢家自己的基础分及成立牌型；杀报加分只由相应被杀的声明者承担。
- 第三家点炮给第四家，不触发未参与放炮的声明者被杀报。
- 25、45是基本H＝5时的总额，不是要完整叠在H上的额外罚款。

例：乙自摸清一色、硬胡，H＝35。甲报听时付乙55；甲原报时付乙75。其他未被杀报者仍按普通自摸各付35。

正常完成杀报属于计分；有合法杀报机会却不胡，属于第10节的一般包牌处罚。

## 6. 牌的归属、鸡分收赔与烧鸡

### 6.1 计牌归属

- 本人手牌、碰杠和仍在本人牌河里的牌，按相应分档统计。
- 牌被别人碰、杠或胡走后，不再作为原出牌者的一张牌重复计鸡；出牌和责任记录仍保留。
- 多响的共同胡牌张，按第3.3节分别给各赢家计鸡分。
- 四张奖励及见面礼以结算时归属判断，不因曾集齐过就永久保留。
- 手牌中的幺筒按最终采用的本牌／癞子用法计分；已经碰、杠的幺筒用碰杠档，不再追加手中本牌档。

每种固定鸡和幺筒在全场第一次实际打出时，若该张仍在牌河，则横放便于辨认；固定鸡的本家首张跟冲（4分档）也横放。首张被碰、杠或胡走后，后续首张标记不递补；跟冲按该次出牌单独标记。之后的2分档固定鸡和幺筒后冲不横放。下一小局重新计次，此标记本身不改变分数。

### 6.2 普通胡牌终局的鸡分

胡牌者按听牌者处理；其他人是否收鸡分看是否听牌，不要求本人也胡牌。

| 双方状态 | 鸡分处理 |
| --- | --- |
| 双方已听 | 各付对方应收的鸡分，抵消后付差额 |
| 一方已听、一方未听 | 未听者支付对方应收鸡分，并向对方赔自己应赔的露出鸡分 |
| 双方未听 | 不互相收赔鸡分 |

听牌者的可收鸡分向另外三家各收一份。未听者只向已听者赔自己牌河、碰杠中的固定鸡和幺筒原有鸡分；手中未露出的鸡不赔。不赔翻牌鸡新增的每张1分、翻鸡三倍增量和翻鸡产生的第五份奖励。碰杠中的固定鸡与幺筒仍按对应原档计赔。收款者自己没有鸡，也能收取未听者的应赔出鸡分。

**普通首冲未听例：** 甲牌河里留有一张20分普通首冲幺筒，甲未听。乙已听无鸡，甲付乙20；丁已听且有2鸡分，甲付丁22；丙未听，甲丙之间此项为0。未听赔付来自实际出鸡，不是无鸡也固定罚20。

上述规则用于普通胡牌终局；一般包牌按第10节，荒庄按第11节，不混用结算公式。

### 6.3 烧鸡

被抢杠的补杠者、点热炮的放炮者烧鸡：

- 本家的鸡分收益归零。
- 仍须支付其他听牌者的鸡分。
- 若本人未听，仍须赔应赔范围内的露出鸡；手中隐藏鸡不赔。
- 烧鸡不改变本人是否听牌。被烧但仍听者，仍可收其他未听者赔出的露出鸡分。
- 烧鸡本身不取消独立见面礼；但若第四张已转归别人、结算只剩三张，则因不满足归属条件而没有见面礼。

例：甲未听并点热炮，露出应赔鸡分8、手中鸡分4；乙已听有2鸡分。只算甲乙鸡分，甲付乙8＋2＝10，手中的4不计赔。

## 7. 固定鸡与普通杠分

### 7.1 固定鸡的分档

幺鸡、八筒、一万互通计分；同一张牌或同一副牌按适用状态取值，不将底、冲、碰档重复相加。

| 状态 | 鸡分 |
| --- | ---: |
| 底鸡 | 未适用冲、碰、杠档时，每张2 |
| 冲鸡／首张跟冲 | 每张4 |
| 全场首碰 | 每副8 |
| 后续碰 | 每副6 |
| 成杠 | 每副10，杠分另结 |

三种固定鸡分别记录全场首冲；全场首碰仍由三种固定鸡共用：

- 每一种固定鸡全场第一次打出均按首冲4计。
- 每家本局自己的第一张出牌，可以用已冲过的同种固定鸡跟冲，仍计4；之后再打已经首冲过的该种鸡，每张2。
- 本局第一次碰任一种固定鸡计8，之后再碰这三种鸡均计6。
- 下一小局重新计次。幺筒不参与这套首冲、首碰计次。

例：甲第二张出牌打八筒为八筒首冲4；乙第二张出牌打一万为一万首冲4；丙第一张打八筒可同种跟冲4。甲先碰幺鸡计8，乙之后碰八筒计6。

### 7.2 杠的类型与独立杠分

| 类型 | 含义 | 普通杠分 | 幺筒杠本身分 |
| --- | --- | --- | --- |
| 明杠 | 接别人打出的第四张直接杠 | 出牌家付5 | 出牌家付20 |
| 转弯杠 | 手中原有三张，刚摸到第四张当次暗杠 | 另外三家各付5 | 另外三家各付20 |
| 补杠 | 已碰出三张，再补第四张成杠 | 另外三家各付5 | 另外三家各付20 |
| 存杠 | 手中已有四张，能杠未杠，之后才杠 | 本项0 | 本项0 |

转弯杠和存杠均属暗杠。存杠不收的是杠分，不自动清零鸡分；已经成立的存杠仍符合第3.2节“自己有杠”的普通点炮胡资格。

独立杠分只对已成功成立的杠记账。普通胡牌或荒庄结算时，杠家已听，按上表收取；杠家未听，按该杠原付款关系向已听的对应玩家反赔同额杠分，双方未听不互付。明杠仅对应原出牌家；转弯杠、补杠对应另外三家。存杠仍没有独立杠分。补杠须先处理抢杠响应；若被合法抢胡，该次补杠不成立，不收这次补杠分，原碰保留。不要先把完整补杠分计入，再叠加抢杠结算。

本家已听、未烧鸡且不计翻鸡、骰子倍数时，固定鸡杠的合计为：

| 情形 | 各家付款 |
| --- | --- |
| 明杠 | 出牌家付10鸡分＋5杠分＝15；另两家各付10 |
| 转弯杠／补杠 | 三家各付10鸡分＋5杠分＝15 |
| 存杠 | 只按鸡分规则结算，没有额外杠分 |

首碰补杠例：原首碰8＋第四张鸡分2＝10，再加杠分5，每家15。碰升级为杠后按最终分档结算，不重复收整笔碰分和整笔杠分；若已记过碰分，只补差额。

## 8. 幺筒专门计分与见面礼

幺筒不与三种固定鸡通分。下列鸡分收赔仍受听牌、烧鸡与终局类型约束；责任款、杠分、见面礼分项记录。

### 8.1 本牌、预冲、首冲、后冲、杠冲

| 状态 | 分值 | 适用方式 |
| --- | ---: | --- |
| 手中幺筒作本牌 | 每张10鸡分 | 按最终拆解判断；作癞子者不计这张本牌鸡分 |
| 预冲 | 30 | 首巡预冲阶段出牌 |
| 普通阶段首冲 | 20 | 预冲阶段结束后，全场第一次普通冲幺筒 |
| 普通阶段后冲 | 15 | 普通首冲之后的普通冲幺筒 |
| 杠冲 | 100 | 自己杠后补摸，紧接着打出幺筒 |

**预冲与普通首冲分别计。** 预冲30不占用普通阶段首冲20；同一局可依次出现预冲30、普通首冲20、后冲15。

预冲阶段持续到所有人完成自己的首张出牌；**最后一家打出的首张幺筒，以及别人直接接这张牌形成的碰、明杠，仍按预冲档处理。** 不按全场前四次弃牌简单判断。

杠冲不要求该幺筒恰好是补摸所得，也不区分杠的类型；必须是杠后补摸紧接着的那次出牌。该张按100计，不再叠加预冲30、首冲20或后冲15；原杠分另结。未被取走时，这100按鸡分的听牌收赔规则处理；若被胡走，则按第8.4节转为点炮责任分。

### 8.2 碰、明杠与责任款

下表按本家已听、未烧鸡列出应收款，未加见面礼、四张奖励或倍数；“其他家”均指其他每家。

| 操作阶段与类型 | 鸡分部分 | 出牌责任款 | 杠本身分 | 责任家合计 | 其他每家 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 普通碰 | 15×3＝45 | 20 | 0 | 65 | 45 |
| 预冲碰 | 30×3＝90 | 30 | 0 | 120 | 90 |
| 普通明杠 | 15×4＝60 | 20 | 20 | 100 | 60 |
| 预冲明杠 | 30×4＝120 | 30 | 20 | 170 | 120 |

明碰、接出牌明杠的责任家，就是该张牌的出牌者。表内100／170已经包含20杠分，不重复再加。

**赚赔同价：** 普通胡牌终局中，本家未听时，露出的幺筒鸡分向已听者反赔，碰杠责任附加随对应玩家反向计算。例：甲碰乙的幺筒，甲未听、乙丙丁均已听，只算甲这副牌，甲付乙65、丙丁各45；对方自己的鸡分另算。预冲责任30同理，不向所有人重复追加责任款。双方都未听时不互结这笔账。

### 8.3 暗杠、补杠与责任继承

普通阶段，甲已听、未烧鸡，未翻中幺筒且无骰子双倍，不计见面礼：

| 情形 | 乙付甲 | 丙付甲 | 丁付甲 |
| --- | ---: | ---: | ---: |
| 甲接乙出牌明杠 | 100 | 60 | 60 |
| 甲自己摸到第四张当次暗杠 | 80 | 80 | 80 |
| 甲存杠 | 60 | 60 | 60 |
| 甲先碰乙，后来成功补杠 | 100 | 80 | 80 |

上表普通碰后成功补杠时，三家各付60鸡分＋20杠分；原放碰者乙的20责任分仍保留。原碰属于预冲档时，其30责任款同样保留。补杠不撤销责任记录，也不重复整笔收取旧碰分。

补杠幺筒不是禁止操作，但其他已听且当前具备合法胡牌资格的人可把该张当癞子抢胡。被抢时，按抢杠、烧鸡处理，不套用成功补杠的收益表；被抢的那张转归赢家，原碰仍为三张，不再算本人凑齐四张。

### 8.4 幺筒点炮

幺筒出牌被胡走后，该张适用的冲分转为放炮家向赢家支付的责任款，不再作为放炮家牌河中的鸡重复结算。

责任原值R取该张实际适用的档位：普通首冲20、后冲15、预冲30或杠冲100。

| 胡来的幺筒用法 | 放炮家另付的责任款 | 该张在赢家处的本牌鸡分 |
| --- | ---: | ---: |
| 作本牌，未翻九筒 | R | 10，向另外三家各收 |
| 作本牌，翻九筒 | 3R | 30，向另外三家各收 |
| 作癞子 | R | 0；责任不触发本牌三倍 |

“作本牌／做硬”只判断这张幺筒的用途，不要求整手同时满足硬胡。H不因翻鸡乘3。多响时，各赢家独立使用本表，责任由放炮家分别支付。

例：甲普通首冲幺筒点炮给乙，乙作本牌，翻九筒，乙的一份胡牌分为H。仅列本次胡牌及该张幺筒的款项，不计其他鸡、杠、见面礼或骰子双倍：

- 甲付乙H＋20×3＋10×3＝H＋90。
- 丙、丁各付乙30。
- 乙本例共收H＋150。

若未翻九筒，则甲付H＋30，丙丁各付10，乙共收H＋50。不能再向乙重复赔同一张冲鸡分，也不向丙丁另赔该张点炮责任。

### 8.5 见面礼与包见面礼

- **结算时四张幺筒仍归本人，另外三家各付100，本人共收300。** 不要求听牌，鸡分另算。
- 统计手牌、碰杠和仍属本人的牌河。曾凑齐后又有一张被别人胡走，结算只剩三张，没有见面礼。
- **包见面礼：** 一家已碰幺筒，别人打出第四张被其胡走形成见面礼，由放炮家承担三份共300；另两家不重复付这项。
- 包见面礼是专门付款责任，不因同一事件再叠加一次一般违规包牌罚款。正常胡牌分和适用鸡分仍结。
- 见面礼不随翻鸡乘3；骰子同点时每份变200，三份共600。
- 烧鸡本身不取消见面礼；结算时是否仍有四张是独立条件。
- 一般违规包牌时不另结见面礼的处理，按第13.2节暂行约定执行。

## 9. 翻鸡、四张奖励与倍数

### 9.1 翻鸡

普通胡牌终局且牌墙还有牌时，翻牌头第一张，按同花色顺位加一确定翻牌鸡；九回一。例如二条→三条、七筒→八筒、九筒→一筒。一般违规包牌不走本节翻鸡计分流程，按第10.4节结算；牌墙耗尽的流局按第11节结算。

- 翻牌鸡不是固定鸡或幺筒时，每张计1鸡分。
- 翻牌鸡恰好是固定鸡或幺筒时，对应鸡分乘3，不再额外加每张1分。
- 幺筒碰、杠责任款随幺筒翻鸡乘3；幺筒点炮责任按第8.4节区分本牌与癞子。
- 杠本身分、见面礼、胡牌分不因翻鸡乘3。
- 牌墙已空时不翻鸡，按第2节处理。

### 9.2 四张额外多算一份

只有该牌成为本局翻牌鸡、且满足四张归属条件时，才增加对应第五份奖励：

| 翻牌鸡类别 | 第五份的原值 | 计算方式 |
| --- | ---: | --- |
| 非固定鸡、非幺筒 | 1 | 四张共5鸡分 |
| 幺鸡、八筒、一万 | 2 | 四张现有分档合计＋2，再乘3 |
| 幺筒 | 10 | 四张各自分档合计＋10，再乘3 |

固定鸡成杠的10鸡分按四张牌的当前分档计；翻中时为（10＋2）×3＝36鸡分，杠分另结。不要仅因10＝5×2就认定已经包含翻鸡第五份。

普通胡牌终局中，未听者只赔牌河、碰杠中固定鸡及幺筒的原有鸡分，不赔翻鸡产生的第五份，也不赔翻鸡三倍增量；不能借手中隐藏牌增加应赔金额。

**幺筒算例：** 四张均归甲，分别为预冲30、普通首冲20、后冲15、手中本牌10，且甲已听未烧鸡。翻九筒，不计其他项目与骰子双倍：

> 每家付甲＝（30＋20＋15＋10＋额外10）×3＋见面礼100＝355。

其中鸡分255，见面礼100，三家合计1065。

### 9.3 幺筒碰杠三倍算例

下表按本家已听、未烧鸡、无骰子双倍计算，只算原鸡分、责任和杠分，**尚未加入凑四张的额外第五份及见面礼**。

| 情形 | 责任家付款 | 其他每家付款 |
| --- | ---: | ---: |
| 普通碰翻九筒 | （45＋20）×3＝195 | 45×3＝135 |
| 预冲碰翻九筒 | （90＋30）×3＝360 | 90×3＝270 |
| 普通明杠翻九筒 | （60＋20）×3＋20＝260 | 60×3＝180 |
| 预冲明杠翻九筒 | （120＋30）×3＋20＝470 | 120×3＝360 |

表内明杠与暗杠、补杠的杠分付款人不同，后两者仍按三家各付杠本身分处理。

### 9.4 骰子同点全局双倍

当前小局开局的两枚骰子点数相同，该小局全部适用分数乘2，包括胡牌分、鸡分、杠分、责任款、见面礼、杀报加分、包牌及流局赔听款。

每个小局按自己的掷骰结果确定倍率。即使连庄，上一小局的同点双倍也不延续到下一小局；庄次编号及整场规定庄次不因骰子同点翻倍。

先确定各分项及翻鸡三倍，再统一乘2，不重复加基础分。见面礼每家100变200；第9.2节算例的每家355变710。固定鸡底分2同时命中翻鸡与骰子双倍时为2×3×2＝12。

连续坐庄不另加连庄分或连庄倍数。

## 10. 过手、必须胡牌与包牌

### 10.1 过手限制

一巡内，幺鸡、八筒、一万、幺筒各自不得同种碰打、打碰：

- 碰打：碰某种鸡后又打同种鸡。
- 打碰：打某种鸡后又碰同种鸡。

不同种类不互相限制，例如先打八筒再碰幺鸡、先碰八筒再打一筒均可以。结算时才确定的翻牌鸡，不追溯用于判此前操作违规。

本巡有合法胡牌机会却选择不胡，无论放弃的是自摸还是点炮胡，通常到本人下一次实际摸牌前不得再胡。碰不重置一巡，杠后实际补摸算下一次摸牌。

**变大牌例外：** 与此前放弃胡牌时相比，牌型确实变大，且合法胡牌分达到45及以上，可以例外胡牌。门槛计基础5及合法牌型，不计鸡分、见面礼或骰子双倍；同样的45分再次出现不算变大。

**抢杠、热炮优先：** 即使本巡已经过胡，遇到抢杠或热炮仍可胡，不要求牌型变大；手中有幺筒时仍须胡，放弃按一般包牌处理。

### 10.2 必须胡牌的场景

以下均以当前具有合法胡牌机会为前提：

1. 本次胡牌可以杀报听或杀原报，却主动放弃。
2. 手中至少有一张幺筒，遇到合法抢杠或热炮胡牌机会，却主动放弃。

第二项只看手中幺筒，不论作本牌还是癞子；已碰、杠的幺筒及牌河幺筒不满足这个手中条件。

上述放弃行为触发一般包牌。普通胡牌若受过手限制，本来不能合法胡牌，就不产生必须胡的义务；选择过不会因此再被判“可杀未杀”。抢杠、热炮不受过手限制，必须胡的义务照常执行。普通胡若违反过手，则按过手违规判包牌。

### 10.3 一般包牌的触发

| 情形 | 规则 |
| --- | --- |
| 大小相公、炸胡 | 大小相公指线下手牌张数异常；炸胡指牌型不成胡或不具备基础胡牌场景资格却宣告胡牌。两者均按一般包牌处理 |
| 违反过手原则 | 违反碰打、打碰或过手胡限制 |
| 自摸未按要求亮牌 | 自摸牌未在侧边亮出，插入手牌后才倒牌等；大牌还须先报牌型 |
| 可杀报听，未杀 | 符合第10.2节第一项 |
| 手中有幺筒，却未抢杠／接热炮 | 符合第10.2节第二项 |

线上如何保留这些操作机会，见第12节。专门“包见面礼”不重复按本表判一次一般包牌。

### 10.4 一般包牌的结算

触发一般包牌，本局立即结束，改按包牌结算；下一局由原庄继续坐庄：

> 单份包牌款B＝全场已听牌者中最高的牌型分P，最低45。

P**不含普通胡牌基础5分**。没有高于45的已听牌型时，按45处理。包牌者向另外三家各付B；其他家是否听牌，不影响收到这笔包牌款。

- 不结鸡分。
- 不再按普通自摸或点炮追加本次正常胡牌款。
- 独立杠分、见面礼不另结，属于第13.2节的暂行约定。
- 骰子同点时，最终包牌款仍乘2。

例：最高通常胡牌总分85中含基础5，对应P＝80。甲触发包牌，向乙、丙、丁各付80，共240；不再另加一笔85胡牌款。

## 11. 流局赔听

牌墙耗尽、最后允许的出牌响应结束后无人胡，进入荒庄。没有剩余牌就不翻鸡。

每位未听者分别向每位听牌者支付：

> 流局赔付＝对方的赔听牌型价S＋本家应赔的露出鸡分L。

L统计未听者的牌河和露出碰杠，不含手中隐藏鸡。S使用该听牌者的牌型价，不普遍再加基础胡分5：

| 听牌类型 | S |
| --- | ---: |
| 软鸡胡 | 5 |
| 硬鸡胡 | 10 |
| 软清一色 | 20 |
| 硬清一色 | 30 |

其他牌型按各自成立的牌型分及叠加规则计价，不加普通基础5。软鸡胡5是本规则给定的赔听价，不改成0；硬鸡胡也不加5变成15。

按此专门公式结算，不再叠加普通胡牌终局中听牌者自身鸡分的收取。例：甲未听，应赔出鸡4；乙听硬清一色，甲付乙30＋4＝34，即使乙自身有6鸡分，也不再加成40。

- 听牌者之间不另互收自身鸡分。
- 全员听牌，没有未听者，不产生本项赔听和赔出鸡款。
- 全员未听，没有听牌收款者，不互相收赔本项。
- 流局无人胡，不产生普通胡牌款，也不触发依点炮、别人自摸成立的杀报。
- 已成立的杠分、符合结算归属条件的见面礼，仍按各自规则处理；流局不自动将全局账目清零。
- 不将一般包牌的“最高牌型、最低45、付全场三人”公式用于流局。

## 12. 定庄、轮庄与线上对局

### 12.1 定庄与轮庄

整场第一小局可由系统分配庄家；线下可协商采用打骰、剪刀石头布、谦让等方式。其余小局按上一小局的结果确定庄家，见下表。

| 本局结果 | 下一局庄家 |
| --- | --- |
| 只有一位赢家，无论自摸还是接炮 | 该赢家 |
| 一炮多响 | 放炮者 |
| 一般违规包牌 | 原庄继续 |
| 流局，四家全听 | 原庄继续 |
| 流局，仅一人未听 | 唯一未听者 |
| 流局，两人或三人未听 | 原庄继续 |
| 流局，四家全未听 | 原庄继续 |

**流局时，仅一人未听由该未听者坐庄；其余情况均由原庄继续。** 两人或三人未听时，无论原庄是否听牌，都不换庄。

例：原庄为甲，只有乙未听时由乙坐庄；乙、丁两人未听时仍由甲继续；只有甲未听时也由甲继续。此流局轮庄方式为本项目约定。

**一般违规包牌结束后，由原庄继续坐庄，不按未听人数另选庄家。** 专门“包见面礼”仍属于普通胡牌结算，按上表单人胡或多响的规则轮庄。

### 12.2 线上保留行为判罚

对局提供新手模式与老手模式，默认新手模式。两种模式使用相同的计分规则与 AI 对手，仅本家操作的防违规辅助不同。

- **新手模式**：系统拦截过手胡、同巡打鸡后碰鸡、同巡碰鸡后打鸡等违规操作；碰牌后若只剩鸡牌可打，也会提前拦截该次碰牌。遇到合法杀报或手持幺筒须抢杠／接热炮时，仅保留胡牌选择，由玩家点击确认。
- **老手模式**：保留玩家自行判断、失误后承担包牌的操作选择，具体按下表执行。

两种模式均由系统维护牌张数量，避免正常操作形成大小相公。新手模式只提供具备基础资格的胡牌操作；老手模式开放主动宣胡，不成胡或不具备场景资格时按炸胡判一般包牌。

| 场景 | 线上安排 | 选择后的处理 |
| --- | --- | --- |
| 牌型不成胡，或不满足鸡胡／大牌等基础场景资格 | 新手模式不生成胡牌操作；老手模式可通过常驻等／胡主动宣胡 | 老手错误宣胡按炸胡包牌 |
| 基础胡牌条件成立，但受过手胡限制 | 胡按钮保留且可选择 | 检查过手及变大牌例外，确实违规就包牌，不记为正常胡牌 |
| 具备碰牌所需牌张，但会构成同巡打碰 | 碰按钮保留且可选择 | 选择后判包牌，不作为有效碰牌继续 |
| 碰鸡后同巡打鸡 | 不以自动禁打替玩家规避处罚 | 实际出牌时判包牌 |
| 有合法杀报机会，或手中有幺筒且有合法抢杠／热炮机会 | 保留胡，以及本来成立的碰、过、出牌等选择；不自动代胡 | 实际选择不胡时，按相应条款包牌 |

老手模式中，按钮可点不等于操作一定合法。碰杠所需牌张仍由系统把关；老手主动宣胡的牌型、场景资格，以及过手、必须胡规则，在选择后判定。触发包牌后按一般包牌结束，不仅仅将该选择当作无效输入忽略。新手模式在操作提交前拦截上述违规，不会因此触发包牌，也不免除正常胡牌中的责任款或流局赔听。

老手模式的“等”不随是否可胡而出现或消失，具体等待流程见第12.4节。保留碰按钮不意味着提供缺少两张同牌等不成立的碰牌。报听后禁杠等既定规则仍执行。没有合法胡牌机会时，不强迫玩家胡，也不因选择过而处罚“必须胡而未胡”。

### 12.3 线上场次与庄次计数

线上开场时选择场次长度，按庄次计算：

| 场次 | 规定庄次 |
| --- | ---: |
| 东风场 | 4 |
| 半庄场 | 8 |
| 全庄场 | 16 |

**连庄不增加庄次；按轮庄规则应换为另一位玩家时，当前庄次才结束。** 庄家人选继续按第12.1节确定，不要求四家按固定顺序各坐一次庄。同一玩家隔开其他人的庄次后再次接庄，计为新的庄次。

1. 开场为第1庄次。
2. 每个小局结束并结算后，按轮庄规则判断下一局庄家。
3. 若仍是原庄，继续当前庄次；无论因庄家胡牌、一般包牌或流局留庄，都不增加庄次。流局仅一人未听且该人就是原庄时，也属于继续当前庄次。一炮多响同样比较新旧庄家：放炮者是原庄则继续当前庄次，是其他人则结束当前庄次。
4. 若应换为另一位玩家，当前庄次结束。尚未达到规定庄次时，庄次编号加1，由该玩家坐下一庄。
5. **最后一个庄次仍允许连庄。** 直到该庄次出现应换庄的结果，结算完该小局后结束整场，不再开启下一庄次。

例如东风场进入第4庄次后，原庄继续连庄两局，期间仍记第4庄次；之后出现应换庄的结果，才结束整场。因此实际小局数可以超过4、8或16，不能用已打小局数代替庄次判断整场结束。

连庄进入的是一个新的小局，仍重新准备牌墙、掷骰和发牌。首巡预冲、固定鸡首冲／首碰计次、原报和报听时点、首次摸牌计次及过手记录，均按新小局重新判断，不跨小局沿用。

界面可显示“第3／4庄次 · 连庄2次”，并另行记录实际已打小局数。每个小局仍按原有规则结算，连庄不另加分或增加倍数。

### 12.4 行牌观察间隔与老手“等”

- 弃牌到下一家摸牌，或该张被碰、杠取走前，至少保留1秒。
- 宣告补杠的抢杠观察窗口为2秒；杠后补摸紧接着打出的首张牌、以及任何幺筒弃牌，其留牌观察间隔为2秒。
- 老手模式在有效对局期间常驻“等”按钮，不以系统判断是否可胡作为显示条件。点等后暂停整桌推进，显示胡与过；有牌型取舍时列出对应胡牌按钮。
- 每人每小局的等额度独立累计15秒，可分次使用，只扣实际等待时长；新小局重置。
- 点胡或过后结束等待。胡按实际资格结算或判罚；过在确有合法机会时按过手、必须胡等规则处理，没有可胡机会时只解除等待。
- 额度耗尽后自动解除等待，等按钮变为常驻胡按钮，不自动代胡。牌局继续推进，不以可胡提示自动停桌。
- 老手可碰、可杠时，碰杠按钮保留到玩家点击碰、杠或过，整桌等待该选择；不因留牌观察间隔结束自动代过碰杠。
- 老手未操作不等于主动过胡。没有待本家选择的碰、杠时，留牌观察间隔结束后可继续摸牌或碰牌，但上一张弃牌的胡口保留到下一次真正出牌前；这段时间随时可点等，再胡原出牌者的牌。已推进的摸牌或碰牌在胡牌确认时恢复到该张弃牌的状态，翻鸡也按该时点的牌墙结算。
- 主动点过立即记录过手；一直未操作则到下一次出牌时才确认放弃，处理过手与必须胡。新的补杠抢杠窗口按抢杠规则处理。
- 等待不改变手牌或胡牌资格。暂离、暂停、切换模式或托管会结束本次等待，已经用掉的本小局时间不返还。

## 13. 结算速查与版本约定

### 13.1 三种终局的结算顺序

| 终局 | 核心处理 |
| --- | --- |
| 普通胡牌 | 核验全部胡牌资格；有牌则翻鸡；复核素胡，按高点法确定最终拆解；计算H、杀报、鸡分、责任、杠分和见面礼；应用倍率后逐家抵消 |
| 一般包牌 | 立即结束；以不含基础5、最低45的最高已听牌型价确定B；向另外三家各付B；按暂行约定不再结本局其他分项 |
| 流局 | 按每个“未听者→听牌者”组合结S＋L；无牌不翻鸡；杠分和见面礼另按规则结算 |

每项先确定原价和付款人，再处理适用的翻鸡三倍，最后应用骰子双倍。相向付款可抵消，但须保留分项依据。**四家净输赢之和应为0。**

完成本小局结算后，按第12.1节确定应续庄还是换庄，再按第12.3节决定继续当前庄次、进入下一庄次或结束整场。最后一小局仍完整结算。

### 13.2 单独保留的暂行约定

**一般违规包牌替代本局常规结算，只结包牌赔付，不另结该局独立杠分和见面礼。**

其中“不算鸡分、不再算自摸”已在玩法答复中明确；杠分、见面礼不另结，是本版本为执行整体包牌流程所采用的暂行整理解读，未表述为玩法提供者逐项确认。该约定不改变普通胡牌中“放炮家包见面礼”的专门付款责任。

### 13.3 本项目采用的线上约定

- 东风场、半庄场、全庄场分别按4、8、16个庄次计算；连庄不增加庄次，整场结束条件见第12.3节。
- 流局仅一人未听时，由该未听者坐庄；未听人数为0、2、3或4时，均由原庄继续。
- 一般违规包牌结束后，由原庄继续坐庄。
- 系统维护牌张数量；新手模式辅助防违规，老手模式可主动宣胡，炸胡、过手及必须胡牌场景按选择后的结果判罚。
- 牌墙摸空后不翻鸡，不另取替代指示牌。
- 后续规则变更应更新版本号、受影响条款及算例。

### 13.4 v1.1 实玩勘误

报听前禁碰杠且须首次出牌；固定鸡按牌种分别首冲；鸡牌过手只限同种；素胡须不求人自摸；赖子按替代牌计鸡分，多胡法按v1.5在翻鸡前确认；第3项已在v1.4按选项3确认，见第13.7节。AI出牌保留一秒缓冲；无任何牌型分时才显示鸡胡。

### 13.5 v1.2 天胡、地胡勘误

本人首次摸牌前已有碰、杠、出牌时，不计天胡或地胡；两次碰牌后才首次正常摸牌胡牌的情况，也只能按实际成立的其他牌型计分。天胡、地胡按庄闲分别命名，保持各加40分。

### 13.6 v1.3 自动高点法

此项在v1.5依据玩法补充调整：现行规则须在翻鸡前确认胡法，只在确认方案内结算。结算中的牌型、鸡分及幺筒用法仍来自同一合法拆解。

### 13.7 v1.4 未听赔付确认（选项3）

未听者按第7.2节反赔独立杠分；牌河及碰杠中的固定鸡、幺筒仍赔原有鸡分，不赔翻鸡新增的鸡分、三倍增量和第五份。听牌者收取翻鸡收益的规则不变，幺筒责任分、见面礼等仍作为独立分项按各自规则结算。一般违规包牌仍只结包牌款。

### 13.8 v1.5 翻鸡前确认与桌面摆放

翻鸡前确认牌型，只有确有风险取舍的赖子大牌提供并列胡牌按钮，不使用选择弹窗；默认指令也先按已知得分确认。首张存活鸡牌横放、不递补，碰牌不指向放碰者。第3点的未听杠分反赔及鸡分原档规则保持不变。

### 13.9 v1.6 行牌节奏与老手等待

普通弃牌留1秒，补杠、杠后首张及幺筒相关窗口留2秒。老手常驻等，每人每小局累计15秒；点等暂停推进，胡／过后恢复，额度用完后常驻胡，错误宣胡判包牌。

### 13.10 v1.7 过手优先级与延长胡口

抢杠、热炮优先于过手，手持幺筒时必须胡。老手未操作时上一张弃牌的胡口保留到下一次出牌前，期间可随时点等后胡；主动点过立即确认放弃。老手可碰、可杠时，碰杠按钮保留到玩家点击，不自动代过。固定鸡的本家首张跟冲与全场首张一样横放。
